1. 처리 목적과 기본 방식

몸무게 일기는 로그인 없이 기기에 몸무게를 기록하고 달력·리포트·위젯으로 확인하는 앱입니다. 기분·일기·사진·식단은 원하는 경우에만 사용할 수 있습니다.

앱에 입력한 기록은 Android의 앱 전용 저장 공간에 보관합니다. 운영자는 기록을 받는 서버를 운영하지 않으며, 앱이 기록을 운영자에게 자동 전송하지 않습니다. 현재 앱에는 광고, 사용 분석, 원격 오류 수집 SDK가 없습니다. 앱 자체는 인터넷 통신 권한을 요청하지 않습니다.

이메일 문의, 사용자가 선택하는 외부 저장 서비스, 개인정보 처리방침 웹페이지와 Google Play·Android의 처리는 아래에서 구분하여 설명합니다.

3. 사진과 기기 권한

사진은 Android의 시스템 사진·파일 선택기에서 사용자가 고른 항목만 읽습니다. 앱은 사진 전체 접근 권한, 카메라 권한, 위치 권한을 요청하지 않습니다.

선택한 사진은 앱 안에 긴 변 최대 2,048픽셀의 JPEG 사본으로 보관하며 원본의 EXIF 위치 정보를 사본에 복사하지 않습니다. 사진 자르기·회전은 앱 사본에 적용하며 갤러리 원본을 수정하지 않습니다. 가져오기·편집 중에는 임시 사본을 사용할 수 있습니다.

알림은 사용자가 기록 알림을 켤 때만 필요한 권한을 요청합니다. 기기 재시작 관련 기능은 설정한 알림과 위젯을 갱신하기 위해 사용합니다. 서버에서 보내는 푸시 알림은 사용하지 않습니다.

앱 잠금은 Android의 생체 인증 또는 기기 화면 잠금 기능을 이용합니다. 앱과 운영자는 지문·얼굴 원본, 기기 PIN·패턴·비밀번호를 받거나 보관하지 않으며 인증 결과만 사용합니다. 앱 잠금은 접근 제어 기능이며 기록 파일이나 백업 파일 전체를 별도로 암호화하는 기능은 아닙니다.

4. 수동 백업과 외부 저장 서비스

전체 백업 ZIP에는 몸무게·일기·식단·연결된 사진·초안·태그·목표·삭제 이력과 지원하는 화면·리포트 설정이 포함됩니다. 기기 인증 정보와 앱 잠금 설정 등 기기 전용 설정은 전체 백업 대상이 아닙니다. CSV 내보내기는 몸무게 목록만 포함합니다.

백업은 사용자가 직접 실행하고 Android의 파일 선택기에서 저장 위치를 고릅니다. Google Drive 등 외부 저장 서비스를 선택하면 사용자의 선택에 따라 해당 서비스로 파일이 저장되고 그 제공자의 약관과 개인정보 처리방침이 적용됩니다. 운영자는 백업 파일을 자동으로 받거나 대신 보관하지 않습니다.

ZIP과 CSV는 암호화하지 않습니다. 파일을 받은 사람은 기록과 사진을 읽을 수 있으므로 저장 위치와 공유 대상을 직접 관리해 주세요. 마지막 성공한 백업과 이후 변경 여부를 표시하더라도 외부 파일의 존재나 자동 동기화를 보장하지 않습니다.

앱은 Android의 자동 클라우드 백업과 기기 이전 대상에서 내부 기록을 제외하도록 설정되어 있습니다. 앱 삭제·저장 공간 초기화·기기 변경 전에 별도로 전체 백업을 보관해야 합니다.

5. 보관 기간과 삭제

기기 안의 기록은 사용자가 삭제하거나 앱 저장 공간을 지우기 전까지 보관합니다. 몸무게·일기·식단은 개별 수정·삭제할 수 있고 작성 중인 초안은 별도로 버릴 수 있습니다.

개별 삭제 후 실행 취소와 복원 충돌 처리를 위한 삭제 이력이나 연결이 끊긴 사진 사본이 남을 수 있습니다. 삭제한 일기·식단의 사진은 7일의 보호 기간을 두고, 사용 중인 일기·식단·초안에서 참조하지 않는 오래된 사본을 앱이 실행될 때 정리합니다. 앱이 실행되지 않는 동안에는 정리가 늦어질 수 있습니다. 삭제 이력에는 기록 식별값·날짜·삭제 시각·사진 식별값 등이 남을 수 있습니다.

설정의 ‘모든 기록 삭제’는 몸무게·일기·식단·모든 초안·사진 사본·사용자 태그·목표·비교 시작일·삭제 이력을 제거합니다. 기본 태그와 화면·알림·위젯·기기 앱 잠금 등 환경 설정은 유지됩니다. 전체 삭제는 실행 취소할 수 없습니다.

앱 삭제나 Android 설정의 저장 공간 초기화로 앱 내부 자료를 제거할 수 있습니다. 갤러리 원본과 이미 내보낸 ZIP·CSV, 문의 이메일, 외부 저장 서비스의 사본은 앱의 기록 삭제로 제거되지 않으므로 각각 별도로 관리해야 합니다.

사진 가져오기·백업 작업의 임시 파일은 작업 종료 시 정리하며, 비정상 종료 등으로 남은 오래된 임시 파일은 이후 앱 실행 시 정리합니다.

문의 자료는 처리 종료 후 30일 이내에 운영자의 메일함에서 삭제합니다. 진행 중인 요청이나 구체적인 분쟁 대응, 법령에 따른 보존 필요가 있는 경우 해당 목적과 필요한 기간에 한해 보관할 수 있습니다. 메일 서비스의 휴지통·백업 등 사본은 해당 서비스의 보관·삭제 절차가 적용될 수 있습니다.
